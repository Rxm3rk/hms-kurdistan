# Cross-module tests

Tests that span modules (BUILD-PROMPT §6.1, §18): the clinical scenario suites that run nightly as release gates (§18.5), end-to-end journeys with Playwright in `en`, `ckb` and `ar` and Maestro mobile flows (§18.2), performance workloads and the scaled, 300-bed and 1,000-bed days (§18.6), chaos and drill suites (§18.7), and conformance suites that run the same signed artefacts on the three-node cell and the central substrate (constitution rule 5). Unit, property and integration tests live with their modules. Every test carries its requirement and hazard IDs in its name or tags (§18.1), uses synthetic data only, and is never weakened, skipped or quarantined to get a green run (§3.5). WP-0.5 builds the scenario-suite framework, WP-0.7 the Playwright, axe and RTL-diff harnesses, WP-0.6 the workload generators and benchmark harness, WP-0.2 and WP-0.3 the first chaos tests, and WP-1.12 and WP-1.13 the conformance suites.
