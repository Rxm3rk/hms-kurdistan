# Content

Kurdistan foundation content and the Kurdistan pack sources (BUILD-PROMPT §6.1, §11, §19.4): order catalogues, formulary and the regional brand master, CDS rules, tariffs and packages, forms, templates and translations, kept as versioned sources and built into signed configuration bundles that are validated and replayed before promotion BUILD → TEST → TRAIN → PROD. Content is a regulated artefact. Every item carries `provenance: synthetic | approved` as data; until clinicians and pharmacists approve real content [HUMAN], sample content is synthetic and flagged NOT FOR CLINICAL USE, uses reserved identifiers (`SYN-` MRNs and accession numbers, GTINs with the GS1 demonstration prefix 952, names such as "Synthdrug A 500 mg tablet", codes from `urn:hms:synthetic:*` code systems, thresholds whose source is recorded as "synthetic"), and blocks promotion to TRAIN or PROD. Licensed files live in `licensed/` and are never committed. WP-0.3 builds the bundle mechanism (`PLT-CFG-01`), WP-1.1 the Kurdistan pack (`PLT-CFG-02`) and WP-1.14 the foundation content (`IMP-FND-01`).
