# Licensed content

Licensed content files go here, placed by a human after accepting their licences (BUILD-PROMPT §3.4 item 5): the drug knowledge base, SNOMED CT (only if licensed, Q-K9), LOINC tables, WHO ICD-10 files (and ICD-10 commercial-use permission), WHO ATC files and licensed scoring instruments such as the Braden Scale. The build agent never downloads, scrapes or ships licensed content and never writes standard codes from memory. This directory is git-ignored except for this README, so nothing placed here is committed. The build provides the loaders, the checksum verification (each loader checks the file's checksum against a recorded value before loading and refuses a mismatch) and their tests on synthetic files; until the real files exist, synthetic code systems (`urn:hms:synthetic:*`) stand in (§19.4). WP-1.1 writes the terminology loaders (LOINC, UCUM, ICD-10, ATC), WP-1.5 the drug-KB adapter's loader, and later work packages any other licensed content they need [HUMAN: licences].
