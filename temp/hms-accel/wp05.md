1. 4. Property tests: ≈1,000 sequences per machine in the fast tier; the 10⁶-sequence nightly run wired into the nightly tier (`tools/ci/run nightly --list` shows the NOT-BUILT step you implement). Record the actual sequence counts.
5. A test scaffold per SI (SI-01…SI-21) with a named test for each. How an SI test whose domain does not exist yet reports is decided in this package's specification under §3.5: no silent stubs, never skipped, quarantined or weakened.
6. The scenario-suite framework (§18.5) under `tests/`, for the nightly tier.
