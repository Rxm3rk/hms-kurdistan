## Checked and found sound

- **Rules 1–10 (own script, own loader: only `true`/`false` booleans, duplicate keys rejected, other YAML 1.1 booleans flagged):** all three parse with `on` as a string and validate against the schema (0 errors). `machine` equals the file name. Owners `medications`, `orders` and `lis`. Terminal and initial are states, every from/to is a state, every state is reachable from `initial`. No unknown or unused predicate or effect (MAR 16/5, order 33/19, specimen 21/5). No static nondeterminism ("*" expanded excluding `to`). Liveness holds, and holds even without `MarkEnteredInError` (every non-terminal state has an ordinary path to a terminal state). Every exit from a terminal state carries `privilegedAndAudited`. Every `proposed` edge belongs to a transition. Approval blocks are `requested`, `[]`, `null`, with exactly the §8.4 approvers (pharmacist-panel, nurse-panel, cso ×2; lab-cso). Invariants are well formed, and every HAZ id exists in the hazard log.
- **Completeness against §8.4, R11 §10.2–10.4 and B.3:** every §8.4 row of the three machines is present (order: start, Sign with all §8.4 guard items, Discard, Verify, Hold/Resume, Complete, Discontinue, Mark error; MAR: start, Start/give split by infusion, Complete, NotDone ×2, Stop, Mark error; specimen: the main path, Reject with the five §8.4 reasons plus two from §9.8, the recollection task). Every edge that is not drawn is proposed. The only drawn edge marked proposed is MAR `in-progress→entered-in-error`, through `*` (conservative, acceptable). B.3's `twoIdentifiersConfirmed` is dropped openly and put to the CSO.
- **Runtime determinism of every alternative pair:** MAR override pairs (verification status is one value, and the scan is identified or not); order Sign (`medicationOrder`/`notMedicationOrder`), Resume (`verifiedOrNotMedication`/`medicationAwaitingVerification`), Discontinue ×3 states (`reasonIsReplacement`/complement) and Verify (`controlSetASatisfied`/`controlSetAMismatch`). Each pair is mutually exclusive for every fact value. The cases where both fail (both checks missing on an override, control set A with no dose recorded, a replacement reason without a co-signed Sign) are intended refusals. The specimen has no alternatives.
- **Cross-machine names:** specimen `servedOrderActive` and `servedOrdersEnded` use order.yaml's state names and terminal set. `allTestsFinal` uses result.yaml's `final/amended/corrected`. The override is split between the MAR and the order (ORD-5), and both files describe it the same way apart from mar-01 to mar-03.
- **Events (§8.5):** MAR `MedicationAdministered/NotGiven/AdministrationOverridden` (B.3 names); order `OrderSigned/Modified/Discontinued`, `MedicationVerified` (emitter question ORD-Q1 filed); specimen `SpecimenCollected/Received/Rejected`. No event names are invented, and the gaps are listed as open questions.
- **SI-12:** no guard in the three files reads a financial fact. **SI-05:** the only quantity comparisons are exact comparisons in the same unit, plus time arithmetic. Hazard clause letters cited (for example SI-15 clause h) match the hazard log's `invariant_clauses`.
- **yaml vs md:** transition tables, guards, effects and proposed lists agree in all three files, except for the points above.
