# HospitalManagementSystem

Created in [T3 Code](https://t3.codes).

## Research and planning

This repository currently holds research, planning and the build brief. No product code has been written yet.

- **[BUILD-PROMPT.md](BUILD-PROMPT.md)** is the master build prompt: the complete implementation brief an AI coding agent (or an engineering team) follows to build the Kurdistan system. It fixes the stack, architecture, conventions and safety rules; specifies every module with acceptance tests; lists all 234 backlog features by release; and sequences the work into phases with exit criteria. Its first section has the kickoff, continue and review prompts to paste into a coding session.

- **[BLUEPRINT.md](BLUEPRINT.md)** is the master blueprint (v1.2.1). It covers what to build, for whom, in what order, with what team and budget, and how to go live safely.
- **[BLUEPRINT-KURDISTAN.md](BLUEPRINT-KURDISTAN.md)** is the Kurdistan Region of Iraq edition (v1.1), derived from the master blueprint and the research pack. It opens with a three-minute summary to read aloud. Its Kurdistan-specific facts are local assumptions, marked [L], to be checked before anyone relies on them. A print-ready copy is in [BLUEPRINT-KURDISTAN.pdf](BLUEPRINT-KURDISTAN.pdf) (A4, with bookmarks and clickable contents).
- **[research/00-INDEX.md](research/00-INDEX.md)** is the reading guide to the evidence pack: 16 research reports, the reconciliation log, the glossary and the competing blueprint proposals.
