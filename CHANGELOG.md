# Changelog

All notable changes to HMS Kurdistan are recorded in this file, per release (BUILD-PROMPT §3.1).

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Release identifiers will follow the release trains of ADR-021 once the first release exists. Release notes for users are trilingual (`en`, `ckb`, `ar`) and are generated by the release tier (§19.1); this file is the engineering record they draw on.
