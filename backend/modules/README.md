# Backend application modules

One directory per application module of the module map (BUILD-PROMPT §5.2), each a Gradle project in package `hms.<module>` with hyphens turned into dots. Inside each module (§6.1): `api/` (the only package other modules may import), `domain/` (aggregates, state machines and invariants; pure Kotlin, no framework types), `application/` (command and query handlers, transactions, policy checks), `infrastructure/` (jOOQ repositories, adapters), `web/` (BFF endpoints), `events/` (outbound mappers), with unit, property and integration tests in `src/test`, `src/propertyTest` and `src/integrationTest`. The architecture rules in `platform/arch-rules` apply to every module from its first class. Modules arrive from WP-0.3 onwards, each specified first (§3.2): module spec, state machines, invariants, contracts and hazards before code.

**WP-0.5: state-machine packages ahead of their modules.** §8.4 puts each machine's predicates in its owner module's domain package, so WP-0.5 created the owning modules as Gradle projects before the modules themselves (docs/specs/modules/state-machines-and-invariants.md §3.1, ADR-035): `adt` (`hms.adt.domain.encounter`, `hms.adt.domain.bed`), `orders` (`hms.orders.domain.order`), `medications` (`hms.medications.domain.medicationadministration`), `lis` (`hms.lis.domain.specimen`), `results` (`hms.results.domain.result`) and `scheduling` (`hms.scheduling.domain.appointment`); the credit-claim machine lives in the satellite `../satellites/rcm` (`hms.rcm.domain.creditclaim`). Each package holds only the generated model (`<P>Machine.kt`, generated by `sh tools/hms statemachines generate`; do not edit), the facts its predicates read (`<P>Facts`), the one implementation of the predicates (`<P>Guards`) with its unit tests, and the property tests over random command sequences (`<P>Arbs`, `<P>PropertyTest`, the generated `<P>GeneratedPropertyTest`). These are specification-layer models: no aggregate, command handler or repository exists yet (KA-062). The work package that builds each module adds the rest beside its package.
