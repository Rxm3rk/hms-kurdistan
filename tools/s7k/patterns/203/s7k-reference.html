HMS S7-K kit 0.2.0, reference for the ZPL text-mode patterns at 203 dpi. Open it with NotoSansArabic-Regular.ttf, NotoSansArabic-Bold.ttf, NotoSans-Regular.ttf, NotoSans-Bold.ttf in the same folder, in a browser that shapes with HarfBuzz (Firefox or Chromium). It shows how the text should look; it is not a golden image. Each row's bidi caption states what the Unicode Bidirectional Algorithm gives.
