# apps/mobile (placeholder)

The React Native app (New Architecture, with Expo) lands here (BUILD-PROMPT.md §4.1, §15, ADR-019). WP-0.7
builds its skeleton. The mobile app framework with the encrypted SQLCipher offline store (`PLT-UX-04`) is

mode (result acknowledgement, critical-result read-back, tablet rounds). iOS builds need macOS [HUMAN].
