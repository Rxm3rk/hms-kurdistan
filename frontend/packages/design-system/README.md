# packages/design-system (placeholder)

The one design system, built on React Aria Components, lands here in WP-0.7 (`PLT-UX-01`; BUILD-PROMPT.md
§6.5, §14.2). It holds design tokens and logical CSS only; the patient banner (SI-16) with patient-context
management and re-verification at signing; the sign and co-sign pattern; the command palette; density modes;
and `ClinicalNumber`, which renders clinical numerals in Western digits in every locale. Its strings come
from `@hms/i18n`.
